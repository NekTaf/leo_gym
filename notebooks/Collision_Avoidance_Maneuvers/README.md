# Collision Avoidance Maneuvers (CAMs)

## Overview 

This directory contains the files for training and validating the collision avoidance policy. 

Contents: 
+ ```test_cam_scenario.ipynb```: notebook for testing and visualizing trained policy 
+ ```shap_validation.ipynb```: notebook for running SHAP analysis
+ ```train_cam.py```: Policy training script 
+ ```train_cam_hppo_cfg.py```: Environment and PPO config file
+ ```mc_cam.py```: Monte Carlo script
